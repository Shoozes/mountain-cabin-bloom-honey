# Developer workflow

Keep app source in `src/`, product orchestration/tests in existing `scripts/`
and shader test modules, and assets in `public/`. `source/README.md` and
`tests/product/README.md` are compatibility pointers retained at original
provenance paths, not a second application or mandatory test migration.

Use `.tools/project.json`, typed spec/state and controller operations as the
Gknome ownership contract. Select actual source/test groups from
`summary_bank.json`; credential-bearing `src/lib/auth` is excluded from context
packing. This exclusion never weakens either secret scanner or publication guard.

Run the smallest relevant project check, inspect its result and affected diff,
then the owning broader gates at closeout. Static plans are not executed tests.
Use `tests/foundation/Test-ProjectBinding.ps1` for semantic contracts and
`run.cmd -Task project-test-terrain -AsJson` for the focused existing terrain
owner. App tests and builds own product behavior separately from semantic foundation gates.

Keep `.runtime/` receipts and `.artifacts/` proof under existing owners. Do not
stop retained services, prune unknown output, move purchased art into fixtures,
or make a release/visual acceptance claim from configuration proof.

Original provenance remains the initial older template snapshot. A reviewed
helper migration is recorded separately; a future full foundation refresh must
preserve these customized task IDs, adapters and caller-owned files.

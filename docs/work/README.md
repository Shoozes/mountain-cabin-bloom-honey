# Work queue

`queue/` is the active execution control plane. Each Markdown file owns one
outcome, its stage, scope, Done when conditions, and completion evidence. Select
one item for `/goal`; do not treat the entire future backlog as an objective.

`done/` holds completed items when retaining their evidence is useful. After a
selected item's Done when and verification are proven, move it there or remove
it when no durable evidence is useful. Do this in the completing sprint; a
separate closeout or handoff request is not required, and completed work never
remains in active routing.

`docs/TODO.md` is future backlog only. A requested handoff is optional
person-to-person context after local state is already accurate. Publication is
always a separate explicit route.
